# Rust Workspace Template

This is a template for a Rust workspace with a flat structure and a modern library stack.

## Features

-   **Flat Workspace Structure:** Crates are located at the root of the repository.
-   **Modern Library Stack:** Includes common libraries for error handling, logging, data manipulation, and testing.
-   **CI/CD:** A basic GitHub Actions workflow is included for building and testing.
-   **Renovate:** A Renovate configuration is included to keep dependencies up-to-date.

## Crates

-   `app`: A binary crate that serves as an example application.
-   `lib`: A library crate that contains shared functionality.
